\doxysubsection{Detailed Description}
Binary Search Tree implementation with comprehensive features. 

This class implements a Binary Search Tree (\doxylink{classBST}{BST}) with support for\+:
\begin{DoxyItemize}
\item Insertion and deletion of nodes
\item Tree traversal (preorder, inorder, postorder)
\item ASCII and graphical visualization
\item Serialization to text and binary formats
\item File I/O operations 
\end{DoxyItemize}
